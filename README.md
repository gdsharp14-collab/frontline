# Warsea Conquest

A WWII-era hex strategy wargame for three players on their phones, taking turns whenever they like.

- **Play:** https://gdsharp14-collab.github.io/frontline/
- **The game:** `index.html` (a single web page; games are saved in Firebase)
- **Docs:** [Project outline](docs/1-project-outline.md) · [Game rules](docs/2-game-rules.md) · [Changelog](docs/3-changelog.md)

The repository is still named `frontline`, the game's original working title, so existing links keep working.
